# v-melody
V-Melody 是一個以 VTuber 音樂為主題的前端網站，提供歌曲搜尋、分類篩選、歌手篩選、收藏管理與隨機探索功能，協助使用者整理喜愛的 VTuber 音樂作品，發掘更多值得收藏的歌曲。
# 專案介紹

VTuber 的原創曲、翻唱曲及團體合作曲分散在不同的頻道與平台，使用者不容易集中整理自己喜歡的作品。

因此，本專案希望建立一個簡單易用的音樂收藏平台，讓使用者可以透過關鍵字、歌手名稱及歌曲類型尋找音樂，並建立個人化的收藏清單。
# 使用技術
Vibecoding

HTML5：建立網站結構。

CSS3：負責視覺設計、動畫及響應式排版。

JavaScript：處理搜尋、篩選、排序、收藏、隨機推薦與詳細資訊視窗。

LocalStorage：儲存使用者的收藏紀錄。

# 專案限制與注意事項

本網站為前端展示專案，不提供直接的音訊串流服務。

外部播放功能會開啟 YouTube 搜尋結果。

YouTube 縮圖需要網路連線，實際顯示情況可能受到外部服務影響。

收藏資料儲存在目前瀏覽器的 LocalStorage，不會自動同步到其他裝置或瀏覽器。

歌曲資料主要用於展示搜尋、分類與收藏功能；外部歌曲連結可協助使用者進一步查找作品。
